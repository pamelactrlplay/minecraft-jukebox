# Minecraft Jukebox - Full-Stack Web Application\
Uma aplicação web interativa inspirada na clássica Jukebox do Minecraft, desenvolvida com um visual retrô fiel, player de áudio integrado, persistência de dados e painel de gerenciamento (CRUD) para discos personalizados.

# Tecnologias Utilizadas\
## Front-end: HTML5, CSS3 (Estilização temática do Minecraft) e JavaScript Vanilla.\

## Back-end: Node.js com Express.\

## Banco de Dados: SQLite (sqlite3).\

## Hospedagem / Deploy: Raillway.\

# Como Executar o Projeto Localmente\
Escolha o guia de acordo com o seu sistema operacional:\

## No Linux (Ubuntu / Debian / Fedora)\
Pré-requisitos: Certifique-se de ter o Node.js e o Git instalados na sua máquina.

Abra o terminal e clone o repositório:\

Bash\
git clone https://github.com/pamelactrlplay/minecraft-jukebox.git\
Entre na pasta do projeto:\

Bash\
cd minecraft-jukebox\
Instale as dependências:\

Bash\
npm install\
Inicie o servidor:\

Bash\
node server.js\
Acesse no navegador: Abra o seu navegador e digite: http://localhost:3000\

## No Windows (CMD / PowerShell / Git Bash)\
Pré-requisitos: Baixe e instale o Node.js (versão LTS recomendada) e o Git para Windows.

Abra o Git Bash (ou o Prompt de Comando/PowerShell) e clone o repositório:\
